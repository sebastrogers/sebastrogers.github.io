FASE 1-1 · CONTEÚDO NOVO

A página por dentro

O que o navegador recebe, e como transforma texto em tela.

CONCEITOAula 11

As três linguagens do navegador

Toda página usa até três linguagens, cada uma com um papel. HTML diz o que há na página (estrutura e significado). CSS diz como aparece. JavaScript diz o que acontece quando o usuário age.

exemplo
HTML        o quê     título, lista, botão, formulário
CSS         como      cor, tamanho, posição, colunas
JavaScript  quando    clicou, digitou, chegou dado

hoje: HTML e CSS
Aulas 12 e 13: JavaScript
Pense assimUma casa: o HTML é a planta e as paredes, o CSS é a pintura e os móveis, o JavaScript é a instalação elétrica.
CONCEITOAula 11

Elemento HTML

Um pedaço da página marcado por tags: a de abertura, o conteúdo e a de fechamento. Atributos dão informações extras dentro da tag de abertura. Elementos ficam dentro de outros, formando uma árvore.

exemplo
<a href="cadastro.html">Cadastrar produto</a>
 │  └ atributo      └ conteúdo        └ fecha
 └ tag de abertura

<article>
  <h3>Camiseta básica</h3>   <- dentro do article
  <p>R$ 39,90</p>
</article>
CuidadoTag aberta tem que ser fechada, na ordem certa. <p><strong>oi</p></strong> está errado.
CONCEITOAula 11

O documento HTML

Todo arquivo HTML tem o mesmo esqueleto. O head traz informações sobre a página (título da aba, codificação, CSS). O body traz o que aparece. O lang diz o idioma, para leitores de tela e tradutores.

exemplo
<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <title>Vitrine · Loja de Roupas</title>
</head>
<body>
  ... o que aparece ...
</body>
</html>
CuidadoSem a meta viewport, o celular mostra a página "de longe", minúscula. Ela entra em toda página.

FASE 1-2 · CONTEÚDO NOVO

CONCEITOAula 11

HTML semântico

Usar a tag que diz o que o conteúdo é, e não só como ele fica. header, nav, main, section, article e footer têm significado: o leitor de tela, o buscador e o próximo programador entendem a página sem ver.

exemplo
<!-- sem semântica: tudo é div -->
<div class="topo"> ... </div>
<div class="conteudo"> ... </div>

<!-- com semântica -->
<header> ... </header>
<main>
  <section> ... </section>
</main>
<footer> ... </footer>
Pense assimUm livro com sumário e capítulos, comparado a um bloco de texto corrido. As duas versões têm o mesmo conteúdo, mas só a primeira dá para navegar.

FASE 1-3 · CONTEÚDO NOVO

Acessibilidade

Uma página que só funciona para quem enxerga bem e usa mouse deixa clientes de fora.

CONCEITOAula 11

Acessibilidade na web

Fazer a página funcionar para todas as pessoas, inclusive quem usa leitor de tela, só o teclado ou tem baixa visão. As regras estão na WCAG, a norma internacional do W3C. No Brasil, a Lei Brasileira de Inclusão (Lei 13.146/2015) exige sites acessíveis.

exemplo
o mínimo de toda página:

✔ alt em toda imagem
✔ label ligado a todo campo
✔ títulos em ordem (h1, h2, h3)
✔ contraste suficiente entre texto e fundo
✔ dá para usar só com o teclado (Tab)
Pense assimA rampa ao lado da escada: foi pensada para cadeirantes, e todo mundo com carrinho ou mala acaba usando.
CONCEITOAula 11

alt e label

O alt é o texto da imagem: o leitor de tela lê em voz alta. O label dá nome ao campo: o for do label aponta para o id do campo. Clicar no rótulo também passa a selecionar o campo.

exemplo
<img src="img/logo.svg"
     alt="Logotipo da Loja de Roupas: uma camiseta">

<label for="preco">Preço (R$)</label>
<input id="preco" name="preco" type="number">

<!-- imagem só decorativa: alt vazio -->
<img src="enfeite.svg" alt="">
CuidadoPlaceholder não substitui label: ele some quando a pessoa começa a digitar, e muitos leitores de tela não o anunciam.
Fase 1-3 · Diagnóstico

O que um leitor de tela não consegue entender aqui?

trecho.html
<img src="camiseta.jpg">
<input type="text" placeholder="Nome">
<h1>Vitrine</h1>
<h4>Produtos</h4>

A imagem não tem alt: o leitor diz só "imagem" ou o nome do arquivo.

O campo não tem label: o placeholder some ao digitar.

Os títulos pulam do h1 para o h4: a estrutura fica confusa.

FASE 2-1 · CONTEÚDO NOVO

Seletores e cascata

Como o CSS escolhe em quais elementos aplicar cada estilo, e quem vence quando dois discordam.

CONCEITOAula 11

Regra CSS

Uma regra tem um seletor (em quem aplicar) e uma lista de declarações propriedade: valor. O arquivo .css entra na página por um link no head.

exemplo
/* elemento: todos os botões */
button { background: #1f6f6b; color: #fff; }

/* classe: quem tem class="formulario" */
.formulario { max-width: 420px; }

/* descendente: links dentro do nav */
nav a { color: #fff; }

<link rel="stylesheet" href="estilo.css">
CuidadoPonto antes do nome é classe (.formulario). Sem ponto é elemento (button). Trocar um pelo outro é o erro mais comum.
CONCEITOAula 11

Cascata e especificidade

Quando duas regras mandam no mesmo elemento, vence a mais específica: id vence classe, que vence elemento. Se empatarem, vence a que vem por último no arquivo.

exemplo
p           { color: black; }   /* elemento: fraco */
.preco      { color: green; }   /* classe: médio   */
#destaque   { color: red; }     /* id: forte       */

<p class="preco" id="destaque">R$ 39,90</p>
<!-- fica vermelho -->
Pense assimUma ordem do gerente vale mais que um aviso no mural; entre dois avisos do mesmo nível, vale o mais recente.
Fase 2-1 · Quem vence?

De que cor fica o botão?

estilo.css
button { background: gray; }
.comprar { background: green; }
button { background: blue; }

<button class="comprar">Pôr no carrinho</button>

Verde. A classe .comprar é mais específica que o elemento button, então vence mesmo vindo antes.

Entre as duas regras de button, a azul viria por último, mas nenhuma das duas vence a classe.

FASE 2-2 · CONTEÚDO NOVO

Modelo de caixa

Para o CSS, todo elemento é uma caixa. Entender a caixa resolve metade dos problemas de layout.

CONCEITOAula 11

Modelo de caixa

Todo elemento é uma caixa em camadas: o conteúdo, o padding (espaço por dentro), a border (a borda) e a margin (espaço por fora, até a próxima caixa).

exemplo
article {
  padding: 16px;             /* dentro  */
  border: 1px solid #e2dccd; /* borda   */
  border-radius: 12px;       /* cantos  */
  margin: 0 0 20px;          /* fora    */
}
CuidadoPor padrão, width mede só o conteúdo: padding e borda somam por fora. Com box-sizing: border-box, a largura inclui tudo. Use em todo projeto.
Fase 2-2 · Na imagem

As quatro camadas de uma caixa

CONCEITOAula 11

Variáveis CSS

Valores com nome, definidos uma vez em :root e usados com var(...). Mudar a cor da marca vira mudar uma linha.

exemplo
:root {
  --verde: #1f6f6b;
  --borda: #e2dccd;
}

header { background: var(--verde); }
button { background: var(--verde); }
article { border: 1px solid var(--borda); }
Pense assimAs constantes do Python (FRETE_FIXO = 15.0), agora no CSS.
FASE 2-3 · CONTEÚDO NOVO

Flexbox e Grid

Duas ferramentas de layout: uma para enfileirar, outra para montar grades.

CONCEITOAula 11

Flexbox

Organiza os filhos de um elemento numa direção: em linha (padrão) ou em coluna. gap dá o espaço entre eles, align-items alinha no outro eixo e margin-left: auto empurra um item para o fim.

exemplo
header {
  display: flex;          /* filhos lado a lado */
  align-items: center;    /* centralizados na altura */
  gap: 16px;
}
nav { margin-left: auto; }   /* menu vai para a direita */

.formulario {
  display: flex;
  flex-direction: column; /* um embaixo do outro */
}
Pense assimUma fila: todo mundo numa linha só, e você decide o espaço entre as pessoas e quem fica no fim.
CONCEITOAula 11

Grid

Organiza os filhos em linhas e colunas ao mesmo tempo. grid-template-columns diz quantas colunas e de que largura; 1fr é "uma fração do espaço que sobra".

exemplo
section {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 colunas iguais */
  gap: 20px;
}

/* o título ocupa a linha inteira */
section h2 { grid-column: 1 / -1; }
Pense assimUma prateleira com nichos do mesmo tamanho: cada produto cai no próximo nicho livre.
Fase 2-3 · Comparação

Flexbox ou Grid?

FlexboxGrid
Direçõesuma: linha ou colunaduas: linhas e colunas
Quem mandao tamanho do conteúdoa grade definida no pai
Bom paramenu, barra do topo, botões alinhados, formulário em colunavitrine de cartões, painel, a página inteira
Na lojaheader e .formularioa section de produtos

Não é um ou outro: a mesma página usa os dois, cada um onde faz sentido.

CONCEITOAula 11

Telas pequenas (media query)

Um bloco de CSS que só vale sob uma condição, como a largura da tela. Assim a mesma página fica em 3 colunas no computador e em 1 no celular.

exemplo
@media (max-width: 700px) {
  section {
    grid-template-columns: 1fr;  /* uma coluna */
  }
  header { flex-wrap: wrap; }
}
CuidadoTeste no DevTools: o ícone de celular (Ctrl+Shift+M) simula telas de vários tamanhos.
