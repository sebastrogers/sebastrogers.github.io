Entrar

O editor publica direto no repositório sebastrogers/sebastrogers.github.io. Para isso ele precisa de um token do GitHub, que fica guardado só neste navegador.

Como gerar o token (uma vez só)
  1. Abra GitHub → Fine-grained token.
  2. Nome: editor do blog. Validade: a que preferir (até 1 ano).
  3. Repository access: Only select repositories → sebastrogers.github.io.
  4. Permissions → Repository → Contents: Read and write. Nada mais.
  5. Gere, copie e cole aqui.

O token só consegue mexer neste repositório. Se perder o computador, é só revogá-lo na mesma página do GitHub.
